# Blendique – Coffee Shop Website

## About the Project

Blendique is a coffee shop website designed to provide customers with an interactive and user-friendly online experience. The website allows users to explore the coffee shop, browse its offerings, customize their orders, and interact with different website features.

The project focuses on combining an attractive user interface with backend functionality using Java technologies and a MySQL database.

## Features

- **Home Page:** Introduces the Blendique coffee shop.
- **Menu:** Displays the available products and offerings.
- **Product Customization:** Allows users to personalize their selections.
- **Shopping Cart:** Provides an interface to manage selected items.
- **Login and Registration:** Provides user account functionality.
- **About Us:** Shares information about the coffee shop.
- **Backend Integration:** Connects frontend pages with Java-based backend functionality.
- **Database Management:** Uses MySQL to store and manage application data.

## Installation and Setup

1. Clone or download this repository.
2. Open the project in Apache NetBeans.
3. Configure the Java application server.
4. Set up the MySQL database using phpMyAdmin or MySQL.
5. Configure the database connection in the project.
6. Run the project through the configured server.

## Database

Blendique uses MySQL for database operations. The database must be configured locally before running the complete application.
